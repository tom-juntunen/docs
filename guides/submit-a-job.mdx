This guide covers the complete multi-file submission workflow. All Open API requests use `https://plangrep.com`.

<Steps>

### Create or select a ready project

```bash
curl -X POST https://plangrep.com/api/open/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: project-my-order-123" \
  -d '{"name":"My Construction Project"}'
```

Poll `GET /api/open/v1/projects/{projectId}` until `project.status` is `"ready"`.

### Create a job

```bash
curl -X POST https://plangrep.com/api/open/v1/projects/proj_abc123/jobs \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: job-my-order-123" \
  -d '{"externalId":"my-order-123"}'
```

The job starts in `awaiting_uploads`.

### Register the files

Validate each local filename, exact byte size, and MIME type. Calculate the SHA-256 digest of each exact file before registration.

```bash
curl -X POST https://plangrep.com/api/open/v1/jobs/job_xyz789/uploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "files": [
      {
        "fileName": "A101-floor-plan.pdf",
        "fileSize": 52428800,
        "contentType": "application/pdf",
        "sha256": "a3f1b2c4d5e6f7081920a1b2c3d4e5f6a7b8c9d0e1f2031415161718191a1b1c"
      },
      {
        "fileName": "Division-03-concrete-spec.pdf",
        "fileSize": 10485760,
        "contentType": "application/pdf",
        "sha256": "b4e2c3d5e6f7081920a1b2c3d4e5f6a7b8c9d0e1f2031415161718191a1b1c2d"
      }
    ]
  }'
```

Do not include `classification`. Plangrep determines page families during preflight.

### Upload each accepted file

An accepted registration returns `uploadMode: "direct_put"`, a signed `uploadUrl`, and `uploadHeaders`.

```bash
curl -X PUT "UPLOAD_URL" \
  -H "content-type: application/pdf" \
  --data-binary @A101-floor-plan.pdf
```

Send every returned header exactly. A `status: "skipped"` result requires no PUT.

### Track automatic processing

There is no completion request. R2 notifies Plangrep after each object is stored. Plangrep computes the canonical SHA-256, validates the byte count and file type in quarantine, checks the malware blocklist, and starts processing clean content.

Poll `GET /api/open/v1/jobs/{jobId}` until the job reaches a terminal status:

```bash
curl https://plangrep.com/api/open/v1/jobs/job_xyz789 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

See [Poll job status](/guides/polling-and-webhooks).

</Steps>
