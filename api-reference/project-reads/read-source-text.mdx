Reads expanded content for a source entity identified by a `sourceCatalogUri`. When structured normalized data is available, the response returns `normalizedData`; otherwise it returns bounded extracted text. Use this endpoint for sources such as drawing regions, sheets, and document entities. For specification section evidence, use [Get Spec Section](/api-reference/project-reads/get-specification-section) instead so you receive untruncated section text and structured spec fields.

## Endpoint

```
POST https://plangrep.com/api/open/v1/projects/{projectId}/source-text
```

## Path Parameters

<ParamField path="projectId" type="string" required>
  The unique identifier of the project that owns the source entity.
</ParamField>

## Request Body

Content-Type: `application/json`

<ParamField body="sourceCatalogUri" type="string" required>
  Opaque URI identifying the source entity whose text you want to retrieve. Obtain this value from a `sourceCatalogUri` field on a search hit or from the source catalog. Must be at least **1 character**.
</ParamField>

<ParamField body="reviewId" type="string">
  Optional review context identifier. When provided, scopes the text retrieval to sources associated with a specific review.
</ParamField>

<ParamField body="cursor" type="string">
  Pagination cursor. Pass the `nextCursor` value from a previous response to retrieve the next chunk of text. Omit to start from the beginning.
</ParamField>

<ParamField body="maxChars" type="integer">
  Maximum number of characters to return in a single response. Must be between **1** and **50,000**. If the source text exceeds this limit, use `nextCursor` to retrieve the remainder.
</ParamField>

<ParamField body="facetId" type="string">
  Optional specification facet identifier or facet key. When provided, text retrieval is scoped to that facet's source or match text artifacts.
</ParamField>

<ParamField body="textKind" type="string">
  Controls the format and scope of returned text. One of:

  | Value | Description |
  |-------|-------------|
  | `text` | Plain text extracted from the source (default). |
  | `markdown` | Text formatted as Markdown, preserving structure where detected. |
  | `page_regions` | Text organized by detected page regions. |
  | `facet_source_text` | Full source text for the selected specification facet. Use with `facetId`. |
  | `facet_match_text` | Match-focused text for the selected specification facet. Use with `facetId`. |
</ParamField>

## Response

Returns a `SourceTextResponse` object. It contains `contentKind: "normalized_data"` with `normalizedData`, or `contentKind: "text"` with bounded text and pagination fields. It does not repeat source metadata or echo facet metadata.

<ResponseField name="status" type="string">
  Status of the text retrieval operation, usually `ok`.
</ResponseField>

<ResponseField name="sourceCatalogUri" type="string">
  The `sourceCatalogUri` from the request.
</ResponseField>

<ResponseField name="contentKind" type="string">
  Indicates the response form: `normalized_data` or `text`.
</ResponseField>

<ResponseField name="normalizedData" type="object">
  Full public normalized source data. Present only when `contentKind` is `normalized_data`.
</ResponseField>

<ResponseField name="text" type="string">
  The retrieved text content, up to `maxChars` characters or the system default. Present only when `contentKind` is `text`.
</ResponseField>

<ResponseField name="cursor" type="string">
  The numeric character offset used for this response, returned as a string. Present only when `contentKind` is `text`.
</ResponseField>

<ResponseField name="nextCursor" type="string">
  Opaque cursor to pass as `cursor` in the next request to continue reading. `null` when there is no more text. Present only when `contentKind` is `text`.
</ResponseField>

<ResponseField name="returnedChars" type="integer">
  Number of characters actually returned in `text` for this response. Present only when `contentKind` is `text`.
</ResponseField>

<ResponseField name="textLength" type="integer">
  Total character length of the full source text. Useful for progress indication. Present only when `contentKind` is `text`.
</ResponseField>

<ResponseField name="hasMore" type="boolean">
  `true` if additional text is available beyond what was returned in this response. Present only when `contentKind` is `text`.
</ResponseField>

<ResponseField name="textKind" type="string">
  The `textKind` that was applied, echoed back from the request or defaulted by the API. Present only when `contentKind` is `text`.
</ResponseField>

## Example Request

```bash
curl -X POST "https://plangrep.com/api/open/v1/projects/proj_abc123/source-text" \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "sourceCatalogUri": "source-catalog://project_sheet_region:region_204",
    "textKind": "text",
    "maxChars": 5000
  }'
```

## Example Response

```json
{
  "status": "ok",
  "sourceCatalogUri": "source-catalog://project_sheet_region:region_204",
  "contentKind": "text",
  "text": "Apply waterproofing membrane to exterior face of below-grade concrete walls.",
  "cursor": "0",
  "nextCursor": null,
  "returnedChars": 77,
  "textLength": 77,
  "hasMore": false,
  "textKind": "text"
}
```

When normalized source data is available, the response is instead:

```json
{
  "status": "ok",
  "sourceCatalogUri": "source-catalog://project_sheet_region:region_204",
  "contentKind": "normalized_data",
  "normalizedData": {}
}
```

## Paginating Through Long Source Text

When `hasMore` is `true`, pass `nextCursor` back as `cursor` in a subsequent request to read the next chunk:

```bash
curl -X POST "https://plangrep.com/api/open/v1/projects/proj_abc123/source-text" \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "sourceCatalogUri": "source-catalog://project_doc:doc_018",
    "textKind": "text",
    "maxChars": 5000,
    "cursor": "5000"
  }'
```

Repeat until `hasMore` is `false`.

## Error Responses

| Status | Description |
|--------|-------------|
| `400`  | Invalid request body - `sourceCatalogUri` missing or empty, `maxChars` out of range. |
| `401`  | Missing or invalid Bearer token. |
| `404`  | Project or source entity not found. |
