Searches indexed sources within a project, including drawing regions, specification sections, and document entities. Use `mode: "semantic"` for vector search, `mode: "grep"` for keyword and boolean prepared-text search, `mode: "regex"` for regular expression search, or `mode: "auto"` for semantic-first behavior with keyword follow-up guidance. Returns hits with snippets, source metadata, and any artifacts exposed for that source. For specification hits, use the returned `source.documentId` and the section ID encoded in `source.id` or `sourceCatalogUri` with the specification section endpoints to retrieve full text and structured evidence.

<Warning>
  **409 — Vector index not ready.** `mode: "semantic"` returns `409 Conflict` when the project has searchable sources but the vector index has not finished building. `mode: "auto"` returns `status: "keyword_search_required"` and next actions instead of a `409`, so agent clients can issue a focused `grep` or `regex` follow-up.
</Warning>

## Endpoint

```
POST https://plangrep.com/api/open/v1/projects/{projectId}/source-search
```

## Path Parameters

<ParamField path="projectId" type="string" required>
  The unique identifier of the project to search within.
</ParamField>

## Request Body

Content-Type: `application/json`

<ParamField body="query" type="string" required>
  The search query string. Must be at least **1 character**. For `grep` and `regex`, this can be a plain string or a JSON string with keys such as `all`, `any`, `not`, `regex`, `patterns`, `sourceTypes`, and `query`.
</ParamField>

<ParamField body="mode" type="enum">
  Search mode. Accepted values: `semantic`, `grep`, `regex`, `auto`. Defaults to `semantic`.
</ParamField>

<ParamField body="reviewId" type="string">
  Optional review context identifier. When provided, scopes the search to sources associated with a specific review.
</ParamField>

<ParamField body="entityTypes" type="string[]">
  Optional list of entity type strings to restrict the search to specific source kinds (e.g. `["region", "specification", "doc"]`).
</ParamField>

<ParamField body="maxHits" type="integer">
  Maximum number of search hits to return. Must be between **1** and **50**. Defaults to a system value if omitted.
</ParamField>

<ParamField body="regionKind" type="string">
  Filter hits to regions of this kind (e.g. `detail`, `keynotes`, `schedule`).
</ParamField>

<ParamField body="regionFamily" type="string">
  Filter hits to regions in this family.
</ParamField>

<ParamField body="placedViewKind" type="string">
  Filter hits to sources with this placed-view kind.
</ParamField>

<ParamField body="tableKind" type="string">
  Filter hits to sources with this table kind.
</ParamField>

<ParamField body="partRole" type="string">
  Filter hits to sources with this part role.
</ParamField>

<ParamField body="sheetNumber" type="string">
  Filter hits to sources located on this sheet number.
</ParamField>

<ParamField body="fileName" type="string">
  Filter hits to sources from files whose name contains this substring (case-insensitive).
</ParamField>

<ParamField body="pageNumber" type="integer">
  Filter hits to sources on this specific 1-based page number.
</ParamField>

<ParamField body="classification" type="string">
  Filter hits to sources from files with this classification. One of: `plans`, `specifications`, `documents`, `addenda`, `mixed`, `other`.
</ParamField>

## Response

Returns a `SourceSearchResponse` object.

<ResponseField name="status" type="string">
  Search status. Usually `ok`; `auto` can return `keyword_search_required`.
</ResponseField>

<ResponseField name="queryMode" type="string">
  The mode used for this response: `semantic`, `grep`, `regex`, or `auto`.
</ResponseField>

<ResponseField name="query" type="string">
  The query string echoed back from the request.
</ResponseField>

<ResponseField name="hitCount" type="integer">
  Number of hits returned in this response.
</ResponseField>

<ResponseField name="searchedChunkCount" type="integer">
  Total number of indexed content chunks that were searched.
</ResponseField>

<ResponseField name="hits" type="object[]">
  Array of search hit objects, ordered by descending relevance score.

  <Expandable title="Hit fields">
    <ResponseField name="score" type="number">
      Relevance score for semantic hits. Higher is more relevant.
    </ResponseField>
    <ResponseField name="snippet" type="string">
      A short excerpt of text from the matched source, suitable for display in a results list.
    </ResponseField>
    <ResponseField name="sourceCatalogUri" type="string">
      Opaque `source-catalog://...` URI that uniquely identifies this source. For non-specification sources, pass this to [Read Source Text](/api-reference/project-reads/read-source-text) to retrieve bounded source text. For specification section sources, use the section API instead.
    </ResponseField>
    <ResponseField name="source" type="ProjectSource">
      Structured object describing the matched source entity.

      <Expandable title="ProjectSource fields">
        <ResponseField name="type" type="string">
          The source catalog entity type (e.g. `project_sheet_region`, `project_specification`, `project_doc`, `project_sheet`).
        </ResponseField>
        <ResponseField name="id" type="string">
          The catalog ID of the matched entity, usually in `{type}:{id}` format.
        </ResponseField>
        <ResponseField name="label" type="string">
          Human-readable label for this source (e.g. `DETAIL 3/A5.01`, `Section 03 30 00`).
        </ResponseField>
        <ResponseField name="documentId" type="string">
          Parent document/file ID. For specification hits, use this as the `specId` path parameter when fetching a specification section.
        </ResponseField>
        <ResponseField name="regionId" type="string">
          Present for region hits.
        </ResponseField>
        <ResponseField name="regionFamily" type="string">
          Present for region hits when available.
        </ResponseField>
        <ResponseField name="placedViewKind" type="string">
          Present for region hits when available.
        </ResponseField>
        <ResponseField name="tableKind" type="string">
          Present for table-like region hits when available.
        </ResponseField>
        <ResponseField name="partRole" type="string">
          Present for source parts when available.
        </ResponseField>
        <ResponseField name="normalizedData" type="object">
          Structured region data for normalized region hits. Shape varies by region kind.
        </ResponseField>
        <ResponseField name="sectionNumber" type="string">
          Present for specification hits when available.
        </ResponseField>
        <ResponseField name="sectionTitle" type="string">
          Present for specification hits when available.
        </ResponseField>
        <ResponseField name="artifacts" type="ProjectEntityArtifact[]">
          Artifact objects associated with this source, when available.
        </ResponseField>
        <ResponseField name="imageArtifact" type="ProjectEntityArtifact">
          Primary image artifact for this source, when available.
        </ResponseField>
        <ResponseField name="fileArtifacts" type="ProjectEntityArtifact[]">
          File-oriented artifacts for this source, when available.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Example Request

```bash
curl -X POST "https://plangrep.com/api/open/v1/projects/proj_abc123/source-search" \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "waterproofing membrane below grade",
    "mode": "semantic",
    "maxHits": 5,
    "classification": "specifications"
  }'
```

## Error Responses

| Status | Description |
|--------|-------------|
| `400`  | Invalid request body — `query` missing or empty, invalid regex, `maxHits` out of range, etc. |
| `401`  | Missing or invalid Bearer token. |
| `404`  | Project not found. |
| `409`  | `mode: "semantic"` only: searchable sources exist but the vector index is not ready yet. Retry after a short wait or use `mode: "auto"` for keyword follow-up guidance. Response body: `{ "error": { "code": "source_index_not_ready", "message": "<string>" } }` |
