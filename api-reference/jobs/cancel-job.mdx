---
title: "Cancel a Non-Terminal Plangrep Job"
sidebarTitle: "Cancel Job"
description: "POST /api/open/v1/jobs/:jobId/cancel — cancels a job that has not yet reached a terminal state. Processed pages may still be billed."
---

Cancel an Open API ingestion job that has not yet reached a terminal state. Once cancelled, the job transitions to `cancelled` status and no further processing occurs. Use this endpoint to stop a job that was created in error, is no longer needed, or needs to be restarted with different files. Workspace-upload, saved-run, and review aggregate IDs are read-only on the Open API surface and return the normal not-found response from this route.

## Authentication

Include your API key as `Authorization: Bearer YOUR_API_KEY` in the request headers.

## Endpoint

```
POST https://plangrep.com/api/open/v1/jobs/{jobId}/cancel
```

## Path Parameters

<ParamField path="jobId" type="string" required>
  The unique identifier of an Open API ingestion job to cancel. The job must not already be in a terminal state (`completed`, `completed_with_errors`, `failed`, `cancelled`, or `expired`).
</ParamField>

## Request Body

This endpoint takes no request body.

## Example Request

```bash
curl --request POST \
  --url https://plangrep.com/api/open/v1/jobs/job_01hy3m8qtn2e5r7k9p0w4x1def/cancel \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Accept: application/json"
```

## Response Fields

<ResponseField name="job" type="Job" required>
  The updated job object reflecting the cancelled state.

  <Expandable title="Job object fields">
    <ResponseField name="id" type="string" required>
      Unique identifier for the job.
    </ResponseField>

    <ResponseField name="externalId" type="string | null">
      Client-supplied correlation ID, or `null` if none was provided at creation.
    </ResponseField>

    <ResponseField name="status" type="JobStatus" required>
      Will be `"cancelled"` upon a successful response.
    </ResponseField>

    <ResponseField name="projectId" type="string" required>
      The ID of the parent project.
    </ResponseField>

    <ResponseField name="limits" type="object" required>
      Processing limits that were applied to this job.

      <Expandable title="limits fields">
        <ResponseField name="maxBytesPerFile" type="integer" required>
          Maximum declared bytes for one file. The default is 2 GiB.
        </ResponseField>

        <ResponseField name="maxBytesPerRun" type="integer" required>
          Maximum declared bytes across the job. The default is 10 GiB.
        </ResponseField>

        <ResponseField name="maxFilesPerRun" type="integer" required>
          Maximum files across the job. The default is 5,000.
        </ResponseField>

        <ResponseField name="maxPagesPerPdf" type="integer" required>
          Maximum pages in one PDF. The default is 3,000.
        </ResponseField>

        <ResponseField name="maxPagesPerRun" type="integer" required>
          Maximum prepared pages across the job. The default is 50,000.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="pageCount" type="integer" required>
      Total number of pages that had been submitted for processing at the time of cancellation.
    </ResponseField>

    <ResponseField name="successfulPageCount" type="integer" required>
      Number of pages successfully processed before cancellation.
    </ResponseField>

    <ResponseField name="failedPageCount" type="integer" required>
      Always `0` for a cancelled job. Failed-page counts are reported only for `completed_with_errors` and `failed` jobs.
    </ResponseField>

    <ResponseField name="progress" type="object" required>
      Work-unit progress envelope. See [Job progress](/concepts/jobs#job-progress).
    </ResponseField>

    <ResponseField name="billing" type="object" required>
      Final billing snapshot. Pages processed before cancellation may have been charged.
    </ResponseField>

    <ResponseField name="files" type="object[]" required>
      The first page of attached-file metadata. At most 100 files are returned inline.
    </ResponseField>

    <ResponseField name="fileCount" type="integer" required>
      Total files attached to the job.
    </ResponseField>

    <ResponseField name="filesNextCursor" type="string | null" required>
      Cursor for [List Job Files](/api-reference/jobs/list-job-files), or `null` when the inline page contains every file.
    </ResponseField>

    <ResponseField name="filesTruncated" type="boolean" required>
      Whether more files are available from [List Job Files](/api-reference/jobs/list-job-files).
    </ResponseField>

    <ResponseField name="counters" type="object">
      File-state counts for this Open API ingestion job, including `total`, `uploaded`, `queued`, `preflighting`, `processing`, `ready`, `failed`, `cancelled`, and `blockedCredits`.
    </ResponseField>

    <ResponseField name="resultUrl" type="string">
      API path for the normalized result JSON, such as `/api/open/v1/jobs/{jobId}/result`. Cancelled jobs do not produce a readable result; calling the result endpoint before completion returns an error.
    </ResponseField>

    <ResponseField name="error" type="object | null">
      `null` for cancellations initiated by the user.
    </ResponseField>

    <ResponseField name="createdAt" type="string" required>
      ISO 8601 timestamp of job creation.
    </ResponseField>

    <ResponseField name="updatedAt" type="string" required>
      ISO 8601 timestamp of the cancellation event.
    </ResponseField>

    <ResponseField name="completedAt" type="string | null">
      ISO 8601 timestamp of when the job was cancelled.
    </ResponseField>

    <ResponseField name="expiresAt" type="string" required>
      ISO 8601 timestamp after which the job and its result are no longer accessible.
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  Cancellation only applies to **non-terminal jobs**. Calling this endpoint on a job that is already `completed`, `completed_with_errors`, `failed`, `cancelled`, or `expired` will return an error. Additionally, any pages that Plangrep had already processed at the time of cancellation **may still be billed** — cancellation does not reverse charges for work already performed.
</Warning>
