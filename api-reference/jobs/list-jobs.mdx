---
title: "List User-Visible Jobs for a Plangrep Project"
sidebarTitle: "List Jobs"
description: "GET /api/open/v1/projects/:projectId/jobs — returns the user-visible job feed for a project, newest first."
---

Retrieve the same user-visible job feed as the Plangrep app for a project. It includes Open API ingestion jobs, workspace uploads, saved runs, and one aggregate record per review. Internal preflight, fan-out, and container records remain private. The response is ordered newest first and paginated.

Keys with `jobs:read` receive Open API ingestion jobs, workspace uploads, and saved runs. Review aggregate records require both `jobs:read` and `reviews:read`; without `reviews:read`, they are omitted.

## Authentication

Include your API key as `Authorization: Bearer YOUR_API_KEY` in the request headers.

## Endpoint

```
GET https://plangrep.com/api/open/v1/projects/{projectId}/jobs
```

## Path Parameters

<ParamField path="projectId" type="string" required>
  The unique identifier of the project whose jobs you want to list. Returned as `project.id` from [Create Project](/api-reference/projects/create-project) or [List Projects](/api-reference/projects/list-projects).
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="100">
  Maximum jobs to return. Must be between **1** and **100**.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque pagination cursor returned as `nextCursor` from a previous response.
</ParamField>

<ParamField query="status" type="string">
  Restrict results to one job status.
</ParamField>

<ParamField query="activeOnly" type="boolean">
  When `true`, returns only active jobs. `active_only` is accepted as a compatibility alias.
</ParamField>

## Example Request

```bash
curl --request GET \
  --url "https://plangrep.com/api/open/v1/projects/proj_01hx9z4kqr8e7m3p5n6w2v0abc/jobs?limit=20&activeOnly=true" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Accept: application/json"
```

## Response Fields

<ResponseField name="jobs" type="Job[]" required>
  Normalized jobs belonging to the specified project, ordered newest first. Each job can represent an Open API ingestion, workspace upload, saved run, or review aggregate.

  <Expandable title="Job object fields">
    <ResponseField name="id" type="string" required>
      Unique identifier for the job.
    </ResponseField>

    <ResponseField name="displayName" type="string" required>
      Human-readable display name for the job. Uses `externalId` when supplied, otherwise falls back to the project name and creation date.
    </ResponseField>

    <ResponseField name="activityLabel" type="string" required>
      Label suitable for activity feeds and dashboard rows. Currently matches `displayName`.
    </ResponseField>

    <ResponseField name="externalId" type="string | null">
      Client-supplied correlation ID, or `null` if none was provided at creation.
    </ResponseField>

    <ResponseField name="status" type="JobStatus" required>
      Current status of the job. One of: `provisioning`, `awaiting_uploads`, `uploading`, `preflighting`, `blocked_insufficient_credits`, `processing`, `completed`, `completed_with_errors`, `failed`, `cancelled`, `expired`.
    </ResponseField>

    <ResponseField name="source" type="string">
      Origin of the job: `open_api` or `workspace`. Use `jobType` and `jobKind` to distinguish ingestion, saved-run, and review work.
    </ResponseField>

    <ResponseField name="jobType" type="string">
      Normalized app job type.
    </ResponseField>

    <ResponseField name="jobKind" type="string">
      Normalized app job kind.
    </ResponseField>

    <ResponseField name="consumption" type="object">
      Consumption information when applicable.
    </ResponseField>

    <ResponseField name="projectId" type="string" required>
      The ID of the parent project. Matches the `projectId` path parameter.
    </ResponseField>

    <ResponseField name="project" type="object">
      Parent project summary, when available.

      <Expandable title="project fields">
        <ResponseField name="id" type="string" required>
          Parent project ID.
        </ResponseField>

        <ResponseField name="name" type="string" required>
          Parent project name.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="limits" type="object" required>
      Processing limits applied to this job.

      <Expandable title="limits fields">
        <ResponseField name="maxDeclaredBytes" type="integer" required>
          Maximum total bytes that may be uploaded to this job. Default: `10000000000` (10 GB).
        </ResponseField>

        <ResponseField name="maxFiles" type="integer" required>
          Maximum number of files that may be uploaded to this job. Default: `100`.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="pageCount" type="integer" required>
      Total number of pages submitted for processing.
    </ResponseField>

    <ResponseField name="successfulPageCount" type="integer" required>
      Number of pages processed successfully.
    </ResponseField>

    <ResponseField name="failedPageCount" type="integer" required>
      Number of pages that have failed or have not completed successfully.
    </ResponseField>

    <ResponseField name="progress" type="object" required>
      Dashboard-friendly progress summary with `processedPages`, `totalPages`, `percent`, `phase`, `message`, and `updatedAt`.
    </ResponseField>

    <ResponseField name="billing" type="object" required>
      Billing snapshot for the job.
    </ResponseField>

    <ResponseField name="files" type="object[]" required>
      Metadata for each file attached to the job.
    </ResponseField>

    <ResponseField name="resultUrl" type="string">
      API path for the normalized result JSON, such as `/api/open/v1/jobs/{jobId}/result`.
    </ResponseField>

    <ResponseField name="error" type="object | null">
      Error details when `status` is `failed`, otherwise `null`.
    </ResponseField>

    <ResponseField name="createdAt" type="string" required>
      ISO 8601 timestamp of job creation.
    </ResponseField>

    <ResponseField name="updatedAt" type="string" required>
      ISO 8601 timestamp of the most recent status update.
    </ResponseField>

    <ResponseField name="completedAt" type="string | null">
      ISO 8601 timestamp of when the job reached a terminal state, or `null` if still in progress.
    </ResponseField>

    <ResponseField name="expiresAt" type="string" required>
      ISO 8601 timestamp after which the job and its result are no longer accessible.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="nextCursor" type="string | null" required>
  Cursor to pass as `cursor` for the next page, or `null` when there are no more jobs.
</ResponseField>
