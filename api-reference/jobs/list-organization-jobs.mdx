title: "List Jobs Across Your Organization"
sidebarTitle: "List Organization Jobs"

---

Retrieve the same user-visible job feed as the Plangrep app across every project visible to the authenticated organization key. It includes Open API ingestion jobs, workspace uploads, saved runs, and one aggregate record per review. Internal preflight, fan-out, and container records remain private. Jobs are ordered newest first and returned with an opaque pagination cursor.

Keys with `jobs:read` receive Open API ingestion jobs, workspace uploads, and saved runs. Review aggregate records require both `jobs:read` and `reviews:read`; without `reviews:read`, they are omitted.

Use this endpoint for dashboards, queues, recent-activity views, and billing reconciliation across projects. To list jobs for one project, use [List Jobs](/api-reference/jobs/list-jobs).

## Authentication

Include an API key with the `jobs:read` scope as `Authorization: Bearer YOUR_API_KEY`.

## Endpoint

```
GET https://plangrep.com/api/open/v1/jobs
```

## Query Parameters

<ParamField query="limit" type="integer" default="20">
  Maximum number of jobs to return. Must be between **1** and **100**.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque pagination cursor returned as `nextCursor` from a previous response.
</ParamField>

<ParamField query="projectId" type="string">
  Restrict results to one project. `project_id` is also accepted.
</ParamField>

<ParamField query="status" type="string">
  Restrict results to one job status, such as `processing`, `completed`, or `failed`.
</ParamField>

<ParamField query="activeOnly" type="boolean">
  When `true`, returns only active jobs in `provisioning`, `awaiting_uploads`, `uploading`, `preflighting`, or `processing`. `active_only` is also accepted.
</ParamField>

## Response Fields

<ResponseField name="jobs" type="Job[]" required>
  Jobs matching the current filters, ordered newest first.
</ResponseField>

<ResponseField name="nextCursor" type="string | null" required>
  Cursor to pass as `cursor` for the next page, or `null` when there are no more jobs.
</ResponseField>

Each job uses the normalized app shape documented in [Get Job](/api-reference/jobs/get-job). `source` identifies the origin (`open_api` or `workspace`), while `jobType` and `jobKind` distinguish ingestion, saved-run, and review work. Jobs also include consumption, billing, page and file information when applicable, project metadata, status, timestamps, and a bearer-authenticated `resultUrl`.

## Example Request

```bash
curl "https://plangrep.com/api/open/v1/jobs?limit=10&activeOnly=true" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
