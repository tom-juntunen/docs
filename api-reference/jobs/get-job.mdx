Retrieve a job from the unified user-visible feed by ID. The feed includes Open API ingestion jobs, workspace uploads, saved runs, and one aggregate record per review. Internal records remain private. Use this endpoint to inspect status, source, job type, consumption, billing, file and page information when applicable, project metadata, and `resultUrl`.

Review aggregate records require both `jobs:read` and `reviews:read`. Without `reviews:read`, a review ID returns the normal not-found response without exposing review metadata.

## Authentication

Include your API key as `Authorization: Bearer YOUR_API_KEY` in the request headers.

## Endpoint

```
GET https://plangrep.com/api/open/v1/jobs/{jobId}
```

## Path Parameters

<ParamField path="jobId" type="string" required>
  The unique identifier of a user-visible job. It can be returned by either job-list endpoint.
</ParamField>

## Example Request

```bash
curl --request GET \
  --url https://plangrep.com/api/open/v1/jobs/job_01hy3m8qtn2e5r7k9p0w4x1def \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Accept: application/json"
```

## Job Status Reference

### Non-Terminal Statuses
Jobs in these states are still in progress and may change status with subsequent polling.

| Status | Description |
|---|---|
| `provisioning` | Job infrastructure is being set up. |
| `awaiting_uploads` | Job is ready to receive file uploads. |
| `uploading` | Files are actively being uploaded. |
| `preflighting` | Uploaded files are being validated, classified from page evidence, and priced before processing begins. |
| `blocked_insufficient_credits` | Job is paused — add credits and call [Resume Job](/api-reference/jobs/resume-job). |
| `processing` | Plangrep is actively processing uploaded documents. |

### Terminal Statuses
Jobs in these states will not change further. Results (if any) can be retrieved.

| Status | Description |
|---|---|
| `completed` | All pages processed successfully. Result is available. |
| `completed_with_errors` | Processing finished with partial page-level errors. Partial result is available. |
| `failed` | Processing failed entirely. Check `job.error` for details. |
| `cancelled` | Job was cancelled via the [Cancel Job](/api-reference/jobs/cancel-job) endpoint. |
| `expired` | Job was not completed before its expiry time. |
