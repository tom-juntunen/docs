## Overview

Register each file and its SHA-256 before sending bytes. Plangrep returns a signed `direct_put` instruction for accepted content or a `skipped` result when no logical file was accepted.

After the PUT succeeds, R2 notifies Plangrep automatically. Plangrep computes the canonical SHA-256 from the stored bytes, validates the quarantined content, and starts processing. There is no upload-completion endpoint.

<Note>
  A job accepts up to **5,000 files** and **10 GiB** of declared bytes. Each file can be up to **2 GiB**.
</Note>

## Endpoint

```http
POST https://plangrep.com/api/open/v1/jobs/{jobId}/uploads
```

## Authentication

```http
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

## Path parameters

<ParamField path="jobId" type="string" required>
  The job that will process the files.
</ParamField>

## Request body

<ParamField body="files" type="array" required>
  Contains one or more file declarations.

  <ParamField body="files[].fileName" type="string" required>
    The original filename, including a supported extension.
  </ParamField>

  <ParamField body="files[].fileSize" type="integer" required>
    The exact non-negative byte length.
  </ParamField>

  <ParamField body="files[].contentType" type="string" required>
    The declared MIME type. It must agree with the filename extension.
  </ParamField>

  <ParamField body="files[].sha256" type="string" required>
    The lowercase 64-character SHA-256 digest of the exact file bytes.
  </ParamField>
</ParamField>

Calculate SHA-256 incrementally before registration. Plangrep independently hashes the stored object and rejects bytes that do not match the declaration. Do not send `classification`; Plangrep derives it during preflight.

## Response

**Status: `201 Created`**

<ResponseField name="job" type="object">
  The updated job.
</ResponseField>

<ResponseField name="uploads" type="array">
  One result per accepted or skipped declaration.

  <ResponseField name="uploads[].documentId" type="string">
    The logical document ID assigned to an accepted upload.
  </ResponseField>

  <ResponseField name="uploads[].status" type="string">
    Present as `skipped` when the declaration was not accepted.
  </ResponseField>

  <ResponseField name="uploads[].skippedReason" type="string">
    Explains why a skipped declaration was not accepted.
  </ResponseField>

  <ResponseField name="uploads[].uploadMode" type="string">
    `direct_put` for accepted uploads.
  </ResponseField>

  <ResponseField name="uploads[].uploadUrl" type="string">
    Signed URL that accepts the complete file with PUT.
  </ResponseField>

  <ResponseField name="uploads[].uploadHeaders" type="object">
    Headers that must be sent exactly as returned.
  </ResponseField>

  <ResponseField name="uploads[].expiresAt" type="string">
    Expiration time for the signed instruction.
  </ResponseField>
</ResponseField>

## Example request

```bash
curl -X POST https://plangrep.com/api/open/v1/jobs/JOB_ID/uploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "files": [
      {
        "fileName": "large-drawings.pdf",
        "fileSize": 52428800,
        "contentType": "application/pdf",
        "sha256": "a3f1b2c4d5e6f7081920a1b2c3d4e5f6a7b8c9d0e1f2031415161718191a1b1c"
      }
    ]
  }'
```

## Example response

```json
{
  "job": { "id": "job_01abc123", "status": "uploading" },
  "uploads": [
    {
      "documentId": "doc_01xyz789",
      "uploadMode": "direct_put",
      "uploadUrl": "https://ACCOUNT.r2.cloudflarestorage.com/BUCKET/OBJECT?X-Amz-...",
      "uploadHeaders": {
        "content-type": "application/pdf"
      },
      "expiresAt": "2026-07-14T18:30:00Z"
    }
  ]
}
```

PUT the complete file with every returned header. Then poll the job. Storage confirmation starts verification and processing automatically.
