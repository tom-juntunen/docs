---
title: "Search Projects by Name and Source Hits"
sidebarTitle: "Search Projects"
description: "POST /api/open/v1/projects/search — searches organization projects by name and source content. Supports source search modes, filtering, and pagination."
---

Search across all projects visible to your organization key using a combination of name matching and source search against ingested content. Results include the matching project, the reasons it was matched, and the specific source hits that contributed to the match score. Supports rich filtering by entity type, drawing metadata, and file classification, as well as cursor-based pagination for large result sets.

## Authentication

Include your API key as `Authorization: Bearer YOUR_API_KEY` in the request headers.

## Endpoint

```
POST https://plangrep.com/api/open/v1/projects/search
```

## Request Body

<ParamField body="query" type="string" required>
  The search string. Must be at least 1 character. Used for project name matching and source search across ingested content.
</ParamField>

<ParamField body="projectIds" type="string[]">
  An optional list of project IDs to restrict source search to. When omitted, all projects in your organization are searched.
</ParamField>

<ParamField body="sourceSearchMode" type="enum">
  Runtime source search mode for source hits. Accepted values: `semantic`, `exact`, `grep`, `regex`, `auto`. Defaults to `semantic`.
</ParamField>

<ParamField body="limit" type="integer">
  Maximum number of projects to return per page. Accepted range: `1`–`100`. Defaults to `25`.
</ParamField>

<ParamField body="cursor" type="string">
  Pagination cursor from a previous response's `nextCursor` field. Omit to start from the first page.
</ParamField>

<ParamField body="entityTypes" type="string[]">
  Filter source matches to specific entity types (for example `["regions", "specifications"]`).
</ParamField>

<ParamField body="regionKind" type="string">
  Filter source matches to a specific region kind within drawings.
</ParamField>

<ParamField body="regionFamily" type="string">
  Filter source matches to a specific region family.
</ParamField>

<ParamField body="placedViewKind" type="string">
  Filter source matches to a specific placed-view kind.
</ParamField>

<ParamField body="tableKind" type="string">
  Filter source matches to a specific table kind.
</ParamField>

<ParamField body="partRole" type="string">
  Filter source matches to a specific part role.
</ParamField>

<ParamField body="sheetNumber" type="string">
  Filter source matches to a specific sheet number.
</ParamField>

<ParamField body="fileName" type="string">
  Filter source matches to a specific file name.
</ParamField>

<ParamField body="classification" type="enum">
  Filter source matches by analyzed file classification. Accepted values: `plans`, `specifications`, `documents`, `mixed`.
</ParamField>

<ParamField body="pageNumber" type="integer">
  Filter source matches to a specific page number. Must be `1` or greater.
</ParamField>

## Example Request

```bash
curl --request POST \
  --url https://plangrep.com/api/open/v1/projects/search \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --header "Accept: application/json" \
  --data '{
    "query": "fire-rated door assembly",
    "sourceSearchMode": "semantic",
    "classification": "plans",
    "limit": 10
  }'
```

## Response Fields

<ResponseField name="query" type="string" required>
  The search query string echoed back from the request.
</ResponseField>

<ResponseField name="projects" type="array" required>
  Ordered array of matched projects with supporting evidence.

  <Expandable title="Project match object fields">
    <ResponseField name="project" type="Project" required>
      The matched project object. See [Get Project](/api-reference/projects/get-project) for field definitions.
    </ResponseField>

    <ResponseField name="matchReasons" type="object[]" required>
      Machine-readable reasons why this project was included in results.

      <Expandable title="matchReasons fields">
        <ResponseField name="type" type="string">
          Reason type. Current values include `projectName` and `sourceSemantic`. Source matches can come from `semantic`, `exact`, `grep`, `regex`, or `auto` source search modes.
        </ResponseField>
        <ResponseField name="value" type="string">
          Present for project name matches.
        </ResponseField>
        <ResponseField name="label" type="string">
          Human-readable label for a matching source, when available.
        </ResponseField>
        <ResponseField name="score" type="number">
          Source match score, when available.
        </ResponseField>
        <ResponseField name="sourceCatalogUri" type="string">
          Opaque `source-catalog://...` URI for the matching source, when available.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="sourceMatches" type="ProjectSource[]" required>
      Specific source records that matched the query.

      <Expandable title="sourceMatches fields">
        <ResponseField name="sourceCatalogUri" type="string">
          Opaque `source-catalog://...` URI for the matching source.
        </ResponseField>
        <ResponseField name="type" type="string">
          Source catalog entity type, such as `project_sheet_region`, `project_specification`, `project_doc`, or `project_sheet`.
        </ResponseField>
        <ResponseField name="id" type="string">
          Catalog ID for the matching source.
        </ResponseField>
        <ResponseField name="label" type="string">
          Human-readable source label.
        </ResponseField>
        <ResponseField name="queryMode" type="string">
          Source search mode used for this match: `semantic`, `exact`, `grep`, or `regex`.
        </ResponseField>
        <ResponseField name="score" type="number">
          Match score when available.
        </ResponseField>
        <ResponseField name="snippet" type="string">
          Text snippet that matched the query.
        </ResponseField>
        <ResponseField name="fileName" type="string">
          Source file name for the matched content.
        </ResponseField>
        <ResponseField name="sheetNumber" type="string">
          Sheet number when the match came from a drawing sheet.
        </ResponseField>
        <ResponseField name="pageNumber" type="integer">
          1-based page number for the source content.
        </ResponseField>
        <ResponseField name="artifacts" type="ProjectEntityArtifact[]">
          Artifact objects associated with this source match, when available.
        </ResponseField>
        <ResponseField name="imageArtifact" type="ProjectEntityArtifact">
          Primary image artifact for this source match, when available.
        </ResponseField>
        <ResponseField name="fileArtifacts" type="ProjectEntityArtifact[]">
          File-oriented artifacts for this source match, when available.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer" required>
  Total number of matching projects across all pages.
</ResponseField>

<ResponseField name="limit" type="integer" required>
  The page size limit applied to this response.
</ResponseField>

<ResponseField name="cursor" type="string | null" required>
  The cursor value that was used for this page, or `null` for the first page.
</ResponseField>

<ResponseField name="nextCursor" type="string | null" required>
  Cursor to pass in the next request to retrieve the following page. `null` when there are no further pages.
</ResponseField>

<ResponseField name="returnedCount" type="integer" required>
  Number of projects returned in this response page.
</ResponseField>

<ResponseField name="hasMore" type="boolean" required>
  `true` when additional pages are available beyond this response.
</ResponseField>

<ResponseField name="warnings" type="ProjectSearchWarning[]" required>
  Array of non-fatal warning messages. Empty array when there are no warnings.
</ResponseField>
