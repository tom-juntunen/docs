Retrieve every project visible to the organization that owns your API key. The response includes each project's current status, runtime health, disciplines, and timestamps, giving you a full snapshot of your project inventory in a single call.

## Authentication

Include your API key as `Authorization: Bearer YOUR_API_KEY` in the request headers.

## Endpoint

```
GET https://plangrep.com/api/open/v1/projects
```

## Query Parameters

<ParamField query="include" type="string">
  Set to `overview` to include a dashboard-oriented `overview` object on each project row.
</ParamField>

## Example Request

```bash
curl --request GET \
  --url https://plangrep.com/api/open/v1/projects \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Accept: application/json"
```

## Response Fields

<ResponseField name="projects" type="Project[]" required>
  Array of all projects visible to the authenticated organization.

  <Expandable title="Project object fields">
    <ResponseField name="id" type="string" required>
      Unique identifier for the project.
    </ResponseField>

    <ResponseField name="name" type="string" required>
      Human-readable display name for the project.
    </ResponseField>

    <ResponseField name="projectKind" type='"open_api" | "workspace"' required>
      Project type. API-created projects are `open_api`; projects created in the Plangrep app are `workspace`.
    </ResponseField>

    <ResponseField name="disciplines" type="string[]" required>
      User-supplied discipline tags for this project.
    </ResponseField>

    <ResponseField name="status" type="string" required>
      Current lifecycle status of the project (e.g., `provisioning`, `ready`, `error`).
    </ResponseField>

    <ResponseField name="runtime" type="object" required>
      Runtime health information for the project.

      <Expandable title="runtime fields">
        <ResponseField name="status" type="string" required>
          Current runtime status.
        </ResponseField>

        <ResponseField name="upgradeStatus" type="string | null" required>
          Indicates whether the project runtime is pending an upgrade, or `null` if no upgrade information is available.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="createdAt" type="string" required>
      ISO 8601 timestamp of when the project was created.
    </ResponseField>

    <ResponseField name="updatedAt" type="string" required>
      ISO 8601 timestamp of the most recent update to the project.
    </ResponseField>

    <ResponseField name="overview" type="ProjectOverview">
      Present only when `include=overview` is supplied. See [Get Project Overview](/api-reference/projects/get-project-overview).
    </ResponseField>
  </Expandable>
</ResponseField>

## Example Response

```json
{
  "projects": [
    {
      "id": "proj_01hx9z4kqr8e7m3p5n6w2v0abc",
      "name": "Downtown Office Tower",
      "projectKind": "open_api",
      "disciplines": ["Architecture", "MEP"],
      "status": "ready",
      "runtime": {
        "status": "ready",
        "upgradeStatus": null
      },
      "createdAt": "2024-11-01T14:22:10.000Z",
      "updatedAt": "2024-11-01T14:24:05.000Z"
    }
  ]
}
```

<Note>
  Only projects associated with the organization that owns the API key are returned. Projects from other organizations are never included, even if you have been granted access through other Plangrep interfaces.
</Note>
