---

Ask a project runtime to reconcile its source index. Before its targeted reconciliation pass, this endpoint persists recovery for missing or terminal exact and vector index work. Use it for projects whose files and entities exist but source search is not yet available or appears stale.

Most integrations do not need to call this during the normal upload flow. Use it when `overview.searchReadiness.state` is `not_ready` or `failed`. The endpoint returns `200 OK` only when search is `ready` or `empty`; otherwise it returns `202 Accepted` while durable reconciliation continues. Poll [Get Project Overview](/api-reference/projects/get-project-overview) and use `overview.searchReadiness` as the durable completion signal.

## Authentication

Include an API key with the `jobs:write` scope as `Authorization: Bearer YOUR_API_KEY`.

## Endpoint

```
POST https://plangrep.com/api/open/v1/projects/{projectId}/source-index/reconcile
```

## Path Parameters

<ParamField path="projectId" type="string" required>
  The unique identifier of the project whose source index should be reconciled.
</ParamField>

## Request Body

<ParamField body="limit" type="integer" default="5">
  Maximum number of source-index repair tasks to process in this request. Must be between **1** and **25**.
</ParamField>

## Response Fields

<ResponseField name="project" type="Project" required>
  The project record.
</ResponseField>

<ResponseField name="sourceIndex" type="object" required>
  Source-index recovery and targeted reconciliation results.

  <Expandable title="Source index fields">
    <ResponseField name="recovery" type="object" required>
      Persisted recovery result for missing or terminal exact/vector index work. Includes the resulting search-readiness fields (`state`, `action`, `counts`, `failedFiles`, and `updatedAt`) and `queued`, which indicates whether recovery work was queued.
    </ResponseField>
    <ResponseField name="reconciliation" type="object" required>
      Targeted reconciliation-pass result. Includes `status`, `limit`, vector `processedCount`, `failedCount`, and `results`, plus `unifiedExact` counts and results for exact-index work.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="overview" type="ProjectOverview" required>
  Updated project overview after reconciliation.
</ResponseField>

## Example Request

```bash
curl -X POST https://plangrep.com/api/open/v1/projects/proj_abc123/source-index/reconcile \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "limit": 10 }'
```
